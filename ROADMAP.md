# Roadmap: Python с нуля

Цель — освоить основы программирования, научиться самостоятельно писать небольшие программы и затем попробовать Backend-разработку. Не нужно изучать всё до первой практики: прочитал тему — попробовал в коде.

## 1. Подготовка

- Установить Python и редактор кода (VS Code или PyCharm).
- Научиться запускать `.py`-файлы из терминала.
- Создать репозиторий на GitHub.
- Разобраться с `git add`, `git commit`, `git push`.

Практика: создать `main.py`, вывести `Hello, world!`, отправить код в репозиторий.

## 2. Основы Python

Изучать примерно в таком порядке:

1. `print()`, `input()`, переменные.
2. Типы данных: `str`, `int`, `float`, `bool`.
3. Операции с числами и строками; преобразование типов.
4. Условия: `if`, `elif`, `else`; сравнения и логические операторы.
5. Циклы: `while`, `for`.
6. Списки: создание, добавление, удаление, перебор элементов.
7. Функции: `def`, аргументы, `return`.
8. Обработка ошибок: `try`, `except`.

Практика: выполнить TASK-001 «Список покупок». Если для очередного шага не хватает знаний — изучить нужную тему и вернуться к задаче.

## 3. Закрепление базы

- Словари, множества, кортежи.
- Работа с текстовыми файлами и JSON.
- Модули, импорты и структура проекта.
- Основы ООП: классы, объекты, методы.
- `pip` и виртуальные окружения.
- Отладка кода и простые тесты (`pytest`).

Практика: доработать список покупок — сохранять данные в JSON-файл и загружать их при запуске; написать несколько тестов.

## 4. Основа Backend

- Как работают клиент и сервер.
- HTTP: запросы, ответы, коды состояния.
- REST API и методы `GET`, `POST`, `PUT`, `PATCH`, `DELETE`.
- Основы SQL и PostgreSQL.
- FastAPI: маршруты, параметры, JSON, валидация.
- Подключение базы данных, базовые CRUD-операции.
- Git: ветки и Pull Request.

Практика: превратить список покупок в REST API с хранением данных в PostgreSQL.

## 5. Проба Java

После того как основы программирования станут понятны:

- Установить JDK и IntelliJ IDEA.
- Изучить синтаксис Java и статическую типизацию.
- Разобраться с условиями, циклами, коллекциями, методами и классами.
- Написать консольный список покупок на Java.
- По желанию познакомиться со Spring Boot и сделать простое API.

Сравнить два языка: читаемость кода, удобство разработки, отладку и собственный интерес. После этого выбрать, в каком направлении развиваться дальше.

## Как учиться

- Не заучивать темы без практики.
- Сначала пробовать решить задачу самостоятельно; документацию и объяснения использовать по мере необходимости.
- Не копировать готовую программу целиком, не понимая её.
- Делать небольшие коммиты и задавать вопросы по конкретным трудностям.
- Не переходить к следующему этапу только ради галочки: важно уметь применять изученное.
